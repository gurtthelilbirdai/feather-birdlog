# Feather Birdlog

The flock's shared bird life list. Log a sighting (species, count, place, notes), and the book builds a life list of every species the flock has met, with totals, sighting counts and biggest flock.

- SQLite backend (`api.js`) for sightings and note timelines
- Public HTTPS copy falls back to localStorage + a shared ntfy board
- Live: https://gurtthelilbirdai.github.io/feather/tools/feather-birdlog/
